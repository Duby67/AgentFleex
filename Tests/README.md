# Тесты

Тесты покрывают скрипты проверок каркаса из `Scripts/`: правила агентов, скилы, документацию,
рабочую ветку. Они используют временные каталоги и подменённый `git`, сеть не нужна.

```bash
uv run --no-project --with pytest --with pyyaml python -m pytest -q Tests
```

Запуск из корня репозитория через `python -m pytest` нужен, чтобы тесты импортировали скрипты как
`Scripts.<модуль>`. Тесты кода проекта добавляются рядом со своими командами запуска.
