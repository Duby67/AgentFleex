# Политика безопасности

[English](../SECURITY.md) · **Русский**

## Поддерживаемые версии

Исправления безопасности получает только последний релиз; обновите плагин перед отправкой отчёта.

## Сообщение об уязвимости

Сообщайте приватно через GitHub: откройте вкладку **Security** репозитория и выберите **Report a
vulnerability**. Не открывайте для уязвимости публичный issue, pull request или обсуждение.

Укажите версию плагина, клиент (Claude Code или Codex) и операционную систему, шаги или
минимальный репозиторий, воспроизводящий проблему, и что получает атакующий.

## Охват

AgentFleex запускает другие программы внутри сессии агента:

- хук Read запускает Python-скрипт индекса плагина, который вызывает `git` и, если установлен,
  Universal Ctags;
- скрипты скиллов вызывают `git` и печатают команды проверок, не запуская их; линтеры и проверки
  типов репозитория агент запускает только по задаче или просьбе пользователя.

В охвате, например: хук или скрипт, который сам запускает код репозитория или скачанный инструмент,
внедрение команд через имена файлов или конфигурацию, данные плагина, которые может прочитать или
изменить другой локальный пользователь. Вне охвата: что делает линтер после запуска и поведение
самих клиентов.
